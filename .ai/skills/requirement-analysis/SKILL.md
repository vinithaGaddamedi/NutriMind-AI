# 📋 Requirement Analysis Skill

## Objective
Transform raw user stories (e.g. Jira stories) into structured requirement objects with full traceability:
`Story -> Acceptance Criteria (AC) -> Test Scenario (TS) -> Test Case (TC) -> Automation Script`.

## Rules
- Identify explicit and implicit business rules.
- Highlight ambiguities, missing requirements, and edge case risks.
- Assign unique story and AC identifiers (`MEAL-101`, `AC-01`).
